## ControlLiquidity
Проверка, можно ли докупить FMMM на остаток денежных средств в портфеле

#### Пример
```
{
  "id": "80a82306-e32a-40ae-aecc-7645d0cd0e01",
  "source": "Momentum",
  "type": "ControlLiquidity",
  "ticker": "FMMM",
  "share": null,
  "state": "New",
  "createAt": "2026.09.20 00:00:00",
  "updatedAt": "2026.09.20 00:00:00",
  "completedAt": "2026.09.20 00:00:00"
}
```

#### Обработка
1. Если событие находится в статусе *New*, то перевести текущее событие **MomentumSyncLiquidity** в статус *InProgress*
2. Снять все активные заявки по тикеру FMMM, если они есть
3. Получить стоимость свободных денежных средств
4. Проверяем, если можно купить больше 10, то отправляем заявку
